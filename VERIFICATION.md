## Known divergence from an earlier claim

`raritiesOf(uint256[])` **is** in the live v3 bytecode — selector `0x8bff1fcc` dispatches (a live probe: `raritiesOf([1])` reverts `ERC721NonexistentToken` while `0xdeadbeef` reverts with empty data). It is declared `external view` at `contracts/src/Loopiterns.sol:115`, so every build of this source ships it. It is a batched view getter — it cannot mint, cannot change price, cannot bypass a cap — and the app ABI (`src/web3/loopiterns/abi.ts`) omits it, so no UI code calls it. It must still **not** be redeclared or removed in a way that changes the deployed selector set without a fresh deploy. `docs/launch.md` states this accurately as of this pass.
