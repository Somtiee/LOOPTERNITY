# RUNBOOK — redeploying the collection (new contract on Robinhood 4663)
#
# The live deployment IS Robinhood Chain mainnet 4663 (v3, 2026-09-22), so
# there is no "flip to mainnet" step left. This section is only for the case
# where you deploy a NEW contract — a new v4, or a redeploy after a contract
# change. Steps, in order:
#
# 1. DEPLOY on 4663:
#      cd contracts
#      forge script script/DeployLoopiterns.s.sol:DeployLoopiterns \
#        --rpc-url robinhood --chain 4663 --broadcast --slow
#    (PRIVATE_KEY + MINT_PRICE_WEI come from contracts/.env; the voucher
#    signer key does NOT change — reuse VOUCHER_SIGNER_PRIVATE_KEY above,
#    its address is baked in as mintSigner by the deploy env. Check
#    contracts/.env for a stale MINT_PRICE_WEI before broadcasting.)
# 2. RECORD it in contracts/deployments/robinhood-4663.json as a new version
#    block (address, deploy tx, block, rpc, explorer, and the on-chain cast
#    checks: owner, mintSigner, mintPrice, paused, totalSupply, Multicall3).
#    The existing "v3" block is the template; keep the retired blocks as
#    history.
# 3. SWAP NEXT_PUBLIC_LOOPITERNS_ADDRESS on Vercel (Production + Preview)
#    to the new address, and update the comment above. Redeploy. Never leave
#    an old address in place — the UI would mint against the wrong contract.
# 4. CHAIN CONSTANTS live in src/web3/config.ts — chain id, public RPC,
#    explorer origin, chain labels. Only touch that file if the chain itself
#    changes (it exists so that flip is a single-file edit). The chain id
#    must come from config, never from scattered literals in components or
#    scripts.
# 5. VERIFY before announcing: forge test in contracts/, then the e2e
#    scripts (scripts/e2e-replay.ts, scripts/e2e-browser.ts) against the new
#    address, and a manual mint click-through in a browser wallet.
# 6. HISTORY: retired deployments stay recorded, never deleted. The Arc
#    testnet (5042002) contract is retired only as the app's live chain — it
#    is NOT paused or swept, so if it is ever swept, note that in
#    contracts/deployments/arc-testnet-5042002.json.
# ---------------------------------------------------------------
